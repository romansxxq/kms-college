## 3. Різниця між комутацією каналів і комутацією пакетів

Комутація каналів створює виділений канал між двома вузлами на весь час сеансу зв'язку, як у класичній телефонній мережі. Це дає змогу забезпечити певну пропускну здатність, але під час пауз канал може використовуватися неефективно.

Комутація пакетів розбиває дані на окремі пакети, які передаються мережею та можуть маршрутизуватися різними шляхами. Спільні канали зв'язку використовуються багатьма користувачами, що підвищує ефективність використання мережевих ресурсів.
