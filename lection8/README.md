## 1. Підпрограма cube(x) на RISC-V
За аналогією з підпрограмою `square` з розділу 5 лекції, де використовувалися регістри `a0` та `mv`/`mul`
```
cube:
    mv   t0, a0        # Зберігаємо x у тимчасовому регістрі t0
    mul  a0, t0, t0    # a0 = x * x (x²)
    mul  a0, a0, t0    # a0 = x² * x = x³
    ret                # Повернення за адресою з ra
```

## 2. Трасування регістрів a0 та ra
```
li   a0, 6
jal  ra, square
ret
```
1. Команда li a0, 6 записує число 6 у регістр a0.

2. Команда jal ra, square викликає підпрограму square і зберігає в ra адресу команди, до якої потрібно повернутися після завершення підпрограми.

3. Усередині square число 6 підноситься до квадрата. Після виконання множення регістр a0 містить значення 36.

4. Команда ret повертає виконання до основної програми за адресою, збереженою в ra.

Отже, після завершення підпрограми в регістрі a0 буде число 36, а в ra залишиться адреса повернення.

## 3. Звернення до пам'яті: RISC-V та x86

У RISC-V використовується архітектура типу Load/Store. Це означає, що для читання даних із пам'яті застосовуються окремі команди, наприклад:
```
lw t4, 0(t3)
```
Ця команда зчитує слово з пам'яті за адресою, яка обчислюється як сума значення регістра t3 та зміщення 0, і записує його в t4.

В архітектурі x86 можна використовувати команди, які безпосередньо звертаються до пам'яті, наприклад:
```
mov dx, [si + bx*2]
```
У цьому випадку адреса пам'яті обчислюється з використанням регістрів si і bx та множника 2, а прочитані дані записуються в dx.

Таким чином, головна відмінність полягає в тому, що RISC-V використовує окремі команди для роботи з пам'яттю, а x86 дозволяє виконувати операції з операндами, розташованими безпосередньо в пам'яті.
