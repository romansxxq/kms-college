## Варіант: 8 (ARP)

### 1. Основний RFC протоколу ARP

| Поле | Значення |
|---|---|
| Номер | RFC 826 |
| Повна назва | An Ethernet Address Resolution Protocol: Or Converting Network Protocol Addresses to 48.bit Ethernet Address for Transmission on Ethernet Hardware |
| Публікація | Листопад 1982 року |
| Поточний статус | Internet Standard, STD 37 |
| Автор | David C. Plummer |

Дані перевірено за [IETF Datatracker](https://datatracker.ietf.org/doc/rfc826/). Статус наведено за реєстром: вступний текст 1982 року ще не називав документ стандартом Інтернету.

### 2. Перевірка актуальності

Станом на 28.10.2026 **RFC 826 чинний і не має наступника в полі Obsoleted by**; його доповнюють [RFC 5227](https://datatracker.ietf.org/doc/rfc5227/) про виявлення конфліктів IPv4-адрес і [RFC 5494](https://datatracker.ietf.org/doc/rfc5494/) про розподіл значень ARP.

### 3. Два конкретні факти зі специфікації

1. Поля `ar$hln` і `ar$pln` мають по **8 бітів** і задають довжину апаратної та протокольної адрес у байтах. Джерело: ненумерований розділ **Packet format** у [тексті RFC 826](https://datatracker.ietf.org/doc/html/rfc826).
2. Багатобайтові числа передаються **старшим байтом уперед**; автор окремо звертає увагу на поле коду операції `ar$op`. Джерело: ненумерований розділ **Notes** у [RFC 826](https://datatracker.ietf.org/doc/html/rfc826).

### 4. Підгрупи IEEE 802

| Підгрупа | Область відповідальності |
|---|---|
| [IEEE 802.1](https://1.ieee802.org/) | Архітектура локальних мереж, мости, VLAN, керування та захист доступу до мережі. |
| [IEEE 802.3](https://www.ieee802.org/3/) | Стандарти Ethernet, зокрема рівні MAC і PHY для передавання даних дротовими з'єднаннями. |
| [IEEE 802.11](https://www.ieee802.org/11/abt80211.html) | Стандарти бездротових локальних мереж, зокрема доступ до середовища й фізичний рівень Wi-Fi. |

#### Контрольні запитання

1. **Proposed Standard / Internet Standard:** перший статус означає початковий рівень стандартизації, другий — зрілий стандарт із підтвердженим досвідом реалізації ([RFC 6410](https://www.rfc-editor.org/rfc/rfc6410.html#section-2.2)).
2. **Obsoletes / Updated by:** перше поле перелічує документи, які цей RFC замінив; друге — документи, що його доповнюють. Заміна позначається полем **Obsoleted by**.
3. **802.1 / 802.3:** 802.1 визначає взаємодію й організацію мереж, а 802.3 — роботу Ethernet.
4. **Навіщо перевіряти статус:** за однаковою назвою можна знайти старий RFC, вимоги якого вже змінено або замінено.
