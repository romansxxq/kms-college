## Завдання 2

Спростіть вираз $\overline{A \vee B} \wedge (A \vee B)$ за допомогою закону де Моргана та закону протиріччя,
показавши проміжні кроки, і зробіть висновок, чому результат завжди дорівнює 0.

### Кроки спрощення:

1. **Вихідний вираз:**
   $$\overline{A \vee B} \wedge (A \vee B)$$

2. **Застосування закону де Моргана** ($\overline{A \vee B} = \overline{A} \wedge \overline{B}$):
   $$(\overline{A} \wedge \overline{B}) \wedge (A \vee B)$$

3. **Застосування розподільного (дистрибутивного) закону**:
   $$((\overline{A} \wedge \overline{B}) \wedge A) \vee ((\overline{A} \wedge \overline{B}) \wedge B)$$

4. **Застосування переставного та сполучного законів**:
   $$(A \wedge \overline{A} \wedge \overline{B}) \vee (\overline{A} \wedge B \wedge \overline{B})$$

5. **Застосування закону протиріччя** ($A \wedge \overline{A} = 0$ та $B \wedge \overline{B} = 0$):
   $$(0 \wedge \overline{B}) \vee (\overline{A} \wedge 0) = 0 \vee 0 = 0$$

### Висновок:
Результат завжди дорівнює 0, оскільки вираз є кон'юнкцією (операцією **I**) двох взаємно протилежних умов: довільного виразу $X = (A \vee B)$ та його прямого заперечення $\overline{X} = \overline{A \vee B}$. За законом протиріччя $X \wedge \overline{X} = 0$ незалежно від значень змінних $A$ та $B$.

## Завдання 3

**Умова:** Накресліть схему повного суматора на трьох входах A, B, Cin із підписаними виходами Sum і Cout, вказавши, які вентилі (XOR, AND, OR) реалізують кожен вихід.

### 1. Формули виходів:
* **Сума ($Sum$):** $Sum = A \oplus B \oplus C_{in}$
* **Перенос ($C_{out}$):** $C_{out} = (A \wedge B) \vee (C_{in} \wedge (A \oplus B))$

### 2. Логічні елементи (вентилі):
* **Для $Sum$:**
  * `XOR1`: обчислює $A \oplus B$
  * `XOR2`: обчислює $(A \oplus B) \oplus C_{in} = Sum$
* **Для $C_{out}$:**
  * `AND1`: обчислює перенос першого півсуматора $A \wedge B$
  * `AND2`: обчислює перенос другого півсуматора $C_{in} \wedge (A \oplus B)$
  * `OR1`: об'єднує сигнали переносу в підсумковий $C_{out}$

### 3. Структурна схема:

```text
Входи                                                           Виходи
  A ───┬─────────┐
       │         ├───[ XOR1 ]─── (A ⊕ B) ───┬─────────┐
  B ───┼───┬─────┘                          │         ├───[ XOR2 ]───► Sum
       │   │                                │   ┌─────┘
Cin ───┼───┼────────────────────────────────┼───┼─────┐
       │   │                                │   │     ├───[ AND2 ]───┐
       │   │                                └───┼─────┘              │
       │   │                                    │                    ├───[ OR1 ]───► Cout
       └───┼─────────┐                          │                    │
           └─────────┼───[ AND1 ]─── (A ∧ B) ───┼────────────────────┘
                     └──────────────────────────┘
```
