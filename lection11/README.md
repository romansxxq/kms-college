### 2. GPIO і pull-up резистор

На вхідному піні мікроконтролера без резистора (напряму підключеному лише до кнопки) при розімкненій кнопці утворюється фізично висячий провідник із високим опором3. Він діє як антена, що збирає наводки від на навколишні електромагнітні поля, викликаючи довільне перемикання між $0$ та $1$3. Резистор pull-up чітко фіксує високий рівень 5В під час спокою, а при натисканні кнопки надійно замикає пін на GND (0В) без короткого замикання джерела живлення.

### 3. Приклад використання ШІМ (PWM) замість звичайного GPIO

Наприклад, керування яскравістю світлодіода або швидкістю обертання двигуна постійного струму.

Тому що звичайний цифровий вихід GPIO може видавати лише два стани - 0В (вимкнено) або 5В (увімкнено на повну потужність). ШІМ змінює шпаруватість (тривалість високоімпульсного сигналу відносно періоду), змінюючи середню ефективну напругу (наприклад, 50% ШІМ дає еквівалент 2.5В), що дозволяє плавно регулювати яскравість чи швидкість.
