## 2. Переведення розміру файлу в біти та розрахунок теоретичного часу

Спочатку необхідно перевести розмір файлу з гігабайтів у байти, а потім у біти.

Переведення 50 ГБ у байти:

50 * 1024 * 1024 * 1024 = 53 687 091 200 байтів.

Оскільки один байт містить 8 біт, розрахуємо загальну кількість бітів:

53 687 091 200 * 8 = 429 496 729 600 біт.

Переведемо отримане значення в гігабіти:

429 496 729 600 / 1 000 000 000 = 429,50 Гбіт.

Отже, розмір файлу становить приблизно 429,50 Гбіт.

Для розрахунку теоретичного часу передавання використовується формула:

Час передавання = Розмір файлу / Пропускна здатність.

### 2.1. Внутрішній контролер хоста PCIe 4.0 x4

Пропускна здатність PCIe 4.0 x4 становить 64 Гбіт/с.

Розрахунок:

T = 429,50 / 64 = 6,71 с.

Теоретичний час передавання через PCIe 4.0 x4 становить приблизно 6,71 секунди.

### 2.2. Зовнішній кабель Thunderbolt 3

Пропускна здатність Thunderbolt 3 становить 40 Гбіт/с.

Розрахунок:

T = 429,50 / 40 = 10,74 с.

Теоретичний час передавання через Thunderbolt 3 становить приблизно 10,74 секунди.

### 2.3. Внутрішній інтерфейс диска SATA III

Пропускна здатність SATA III становить 6 Гбіт/с.

Розрахунок:

T = 429,50 / 6 = 71,58 с.

Теоретичний час передавання через SATA III становить приблизно 71,58 секунди.

### 2.4. Порівняння результатів

| Інтерфейс | Пропускна здатність | Теоретичний час |

| Thunderbolt 3 | 40 Гбіт/с | 10,74 с |

## 3. Визначення вузького місця (Bottleneck)

Вузьким місцем системи є внутрішній інтерфейс диска SATA III, пропускна здатність якого становить 6 Гбіт/с.

Ланцюжок передавання даних складається з контролера хоста, зовнішнього кабелю та внутрішнього інтерфейсу накопичувача. Загальна продуктивність такого ланцюжка залежить від найповільнішої ланки.

PCIe 4.0 x4 має пропускну здатність 64 Гбіт/с, а Thunderbolt 3 - 40 Гбіт/с. Обидва інтерфейси здатні передавати дані значно швидше, ніж SATA III.

Тому навіть за умови високої пропускної здатності контролера хоста та зовнішнього кабелю швидкість передавання обмежується інтерфейсом SATA III.

Отже, SATA III є вузьким місцем системи та визначає основний час передавання файлу.

## 4. Розрахунок реального часу з урахуванням накладних витрат

Накладні витрати протоколу зменшують пропускну здатність, доступну для передавання корисних даних.

Для розрахунку реальної швидкості використовується формула:

Реальна швидкість = Номінальна швидкість * (1 - Частка накладних витрат).

Для SATA III накладні витрати становлять 15%, або 0,15 у десятковому вигляді.

Розрахуємо реальну швидкість:

Реальна швидкість = 6 * (1 - 0,15).

Реальна швидкість = 6 * 0,85 = 5,10 Гбіт/с.

Отже, реальна пропускна здатність SATA III з урахуванням накладних витрат становить 5,10 Гбіт/с.

Тепер розрахуємо реальний час передавання файлу:

Реальний час = Розмір файлу / Реальна швидкість.

Реальний час = 429,4967296 / 5,10 = 84,22 с.

Отже, реальний розрахунковий час передавання файлу становить приблизно 84,22 секунди.

### 4.1. Розрахунок відсотка збільшення часу

Щоб визначити, на скільки відсотків реальний час перевищує теоретичний, використаємо формулу:

Збільшення часу = ((Реальний час - Теоретичний час) / Теоретичний час) * 100%.

Підставимо отримані значення:

Збільшення часу = ((84,22 - 71,58) / 71,58) * 100%.

Збільшення часу = приблизно 17,66%.

Отже, через накладні витрати час передавання збільшується приблизно на 17,66%.

## 5. Пояснення природи накладних витрат протоколу

Накладні витрати протоколу — це додаткові дані та службові операції, необхідні для організації передавання інформації. Вони не є безпосередньо корисним вмістом файлу, але забезпечують правильну роботу інтерфейсу.

До накладних витрат можуть належати:

- службові заголовки пакетів

- контрольні дані та підтвердження отримання

- сигнали синхронізації

- витрати на кодування даних

- службова інформація для керування передаванням.

Різні інтерфейси мають різні протоколи роботи, тому їхні накладні витрати відрізняються.

Наприклад, USB4 підтримує передавання різних типів трафіку, зокрема PCIe та DisplayPort, використовуючи механізми тунелювання та мультиплексування. Це потребує додаткової службової інформації для керування передаванням.

У методичних розрахунках можуть використовуватися умовні значення накладних витрат, наприклад 10% для USB 2.0 та 15% для USB4. Фактичні значення залежать від режиму роботи, протоколу та методики обчислення.

У цій роботі для визначення реального часу передавання використовуються накладні витрати SATA III, які за вихідними даними становлять 15%.
